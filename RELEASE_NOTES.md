Version 0.4.4

- New: Server load (Tool menu, and About on the desktop app). Shows what the simulation engine is using on the machine it runs on: memory and CPU now and over the last ten minutes, and how many workers are running.
- New: a built-in test that replays your generated flights as if several people pressed Generate all at once, and turns the result into what a server would need (memory, cores, cloud cost).
- The test uses the flights already generated; its results are discarded.
