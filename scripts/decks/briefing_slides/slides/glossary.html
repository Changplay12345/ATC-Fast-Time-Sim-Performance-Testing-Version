The few technical words, explained

WordMeaning here
RepositoryThe project’s folder on GitHub: all the code, notes and history in one place
CommitOne saved change, with a short note on what it did and why
BuildTurning the code into a program people can install; GitHub does this for Windows and Mac
TestA check the program runs on itself; GitHub runs the whole set on every change
ReleaseA numbered version (for example 0.4.4) published with its installers and update files
Auto-updateThe app checks for a newer release when it starts and installs it on its own
Signing keyA secret file that proves an update really came from us; the app refuses updates without it
Data packA separate download of navigation data, delivered the same way as updates
EngineThe part of the software that calculates the flights; it runs hidden inside the app or on a server
