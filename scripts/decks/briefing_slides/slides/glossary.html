The few technical words, explained

WordMeaning here
RepositoryThe project’s folder on GitHub: code, notes and history in one place
CommitOne saved change, with a short note on what it did and why
BuildTurning code into a program people can install
TestA check the program runs on itself; GitHub runs them all on every change
ReleaseA numbered version (0.4.4) with its installers and update files
Auto-updateThe app finds a newer release at start-up and installs it on its own
Signing keyA secret file proving an update came from us; the app refuses updates without it
Data packA separate download of navigation data, delivered like an update
EngineThe part that calculates the flights; runs inside the app or on a server
