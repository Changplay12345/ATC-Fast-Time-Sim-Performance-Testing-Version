Questions management may ask

What does it cost?

One Claude subscription for the engineer; GitHub is free at our size. No server is needed for building and delivery, which run on GitHub’s machines.

Is our work confidential?

The code and notes pass through Anthropic’s service under business terms. The project holds only test traffic, no real operational data. The key that signs updates never leaves the engineer’s PC. The test project is public by choice; the complete version can be private at no extra cost.

Are we dependent on these tools?

No more than on any supplier. Code, notes and build instructions are ordinary files. Another engineer can continue from the notes; installers can be built on the PC and handed out by hand.

Can an AI be trusted with the code?

Its work is reviewed and tested like any engineer’s. It has made mistakes; the automatic tests and the engineer’s review caught them before release. One start-up fault was found by the test on GitHub, not by a user.

Does it replace the engineer?

No. It changes what the engineer spends time on: less typing and routine checking, more deciding, reviewing and measuring. Ten releases on two platforms in four weeks came from that combination.
