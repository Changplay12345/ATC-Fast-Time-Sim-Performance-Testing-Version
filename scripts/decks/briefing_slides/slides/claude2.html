One of those features: the Server load panel

What it shows

Memory, processor and worker use of the simulation engine, live and over the last ten minutes.

What it can test

Replays a run as if several people pressed Generate at once, and turns the result into a server size.

Why it matters

The cloud and colocation proposals got their numbers from it, not from guesses.
