What GitHub gives us

A full history

Every change is recorded with who made it, when, and why. Any earlier version can be brought back.

Automatic checks

Each saved change runs the project’s tests on GitHub’s own machines and reports pass or fail.

Installers built for us

On each release GitHub builds the Windows installer and the Mac version, on Apple machines we do not own, and tests that each one starts.

Updates delivered to users

The app checks GitHub when it starts, downloads a newer release, checks the signature and installs it. Nobody sends files around.

Control over a release

An update can go to a small share of users first, be held back, or be stopped by changing one file. A faulty version is withdrawn in minutes.

Navigation data on the same path

Updated airspace and procedure data travels to users the same way, separately from the program itself.
