Three roles, one team

Think of a building project. One person decides and inspects, one builds, one stores the materials and delivers the result.

Our engineer

Architect and inspector

Decides what the tool should do next, checks every change, and presses the release button.

Claude

The builder

Writes and tests the program code on the engineer’s PC, measures how fast the simulation runs, and writes every step into the project notes.

GitHub

Warehouse and delivery van

Keeps every version of the software, builds the Windows and Mac installers on its own machines, and hands each new version to every user automatically.

Claude and GitHub on the Simulation Tool · 3

Nothing Claude writes reaches a user without the engineer reviewing it. GitHub does the heavy lifting of building and delivering, on machines we do not own.
