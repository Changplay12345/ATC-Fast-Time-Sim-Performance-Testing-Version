The two tools in plain words

ToolWhat it isWhat it does for usCost
Claude (Claude Code, by Anthropic)An AI assistant that writes the project’s code on our own PC, told what to do in plain languageNew features, fault fixing, tests, speed and memory measurements, project notes, proposals and slidesA monthly subscription
GitHub (by Microsoft)The online home for software projects, used by most of the industryKeeps every version with its history, checks every change, builds the installers, delivers updatesFree at our size

Both are ordinary, widely used services. The code and notes are plain files we can take anywhere.
