The two tools in plain words

ToolWhat it isWhat it does for usWhat it costs
Claude (Claude Code, by Anthropic)An AI assistant that reads and writes the project’s code on our own PC, following the engineer’s instructions in plain languageWrites new features, finds and fixes faults, runs the tests, measures speed and memory, writes the project notes, drafts proposals and slidesA monthly subscription
GitHub (by Microsoft)An online home for software projects, used by most of the software industryKeeps every version of the code with its history, runs automatic checks on every change, builds the Windows and Mac installers, publishes releases that the app downloads by itselfFree at our size

Both are ordinary, widely used services. Neither holds anything we could not take elsewhere: the code, notes and build instructions are plain files kept on GitHub and on the engineer’s PC.
