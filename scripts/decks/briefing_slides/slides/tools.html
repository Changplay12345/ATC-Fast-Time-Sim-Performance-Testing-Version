The two tools in plain words

Claude

Claude Code, by Anthropic. An AI assistant that works on our own PC.

  • Writes new features
  • Finds and fixes faults
  • Runs the tests
  • Measures speed and memory
  • Writes notes, proposals, slides

Cost: a monthly subscription

GitHub

By Microsoft. The online home for most of the world’s software projects.

  • Keeps every version and its history
  • Checks every change
  • Builds the Windows and Mac installers
  • Publishes releases
  • Delivers updates to the app

Cost: free at our size
