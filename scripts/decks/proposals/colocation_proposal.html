Proposal · ATC Fast-Time Simulation Tool

Running the simulation tool on our own server, housed in a data centre

A plan to buy one server, place it in a professional data centre in Bangkok, and pay a fixed monthly fee for the space, power and internet. The company owns the machine; the data centre looks after the room.

From: BearCat AEL Co, engineering Date: 24 October 2026 Period: 15 months

What we propose

Instead of renting computing by the month (the cloud proposal), we buy one small rack-mount server and have a Thai data centre host it. This is called colocation. The data centre provides a locked rack, power with battery and generator backup, cooling and a fast internet line, and its staff can restart the machine or swap a part for us, so nobody has to travel there. Users work exactly as in the cloud option: they open a web address and the server does the calculation. The exact server model is chosen later from the hardware catalogue already prepared; this proposal fixes the budget, not the model.

How it compares with the cloud option

  • Cloud, 15 months: about ฿11,000 expected, ฿35,000 budget. Colocation: about ฿125,000, ฿170,000 budget.
  • Colocation costs more because we buy the machine up front. From month 16 the running cost is ฿2,000 a month, with no charge per simulation run.
  • At today's expected use (2–4 people a day) the cloud is the cheaper choice. Colocation starts to pay back if the tool is used heavily every day for several years, or if the hardware is wanted for other work as well.
  • Both options give users the same web page; switching between them later is a one-day job.

Why choose this option

  • The data stays in Thailand, on a machine we own.
  • Unlimited simulation runs at a fixed monthly fee; no bill that grows with use.
  • A dedicated machine is faster for everyone than a shared cloud instance of the same price.
  • No office space, cooling or power backup needed on our side.

Before it goes live

About six to eight weeks from approval, mostly waiting for delivery:

  • Choose the server from the catalogue and get two supplier quotes.
  • Sign a hosting contract (monthly or yearly; yearly is usually cheaper).
  • Deliver the server to the data centre; the provider installs it.
  • About five days of our engineering time to install the software, add a password and a web address, and measure a real run.

Things to be aware of

  • One machine, no spare: if it fails, the tool is down until the part is replaced (one to three days with on-site warranty). The desktop version covers the gap.
  • The purchase cannot be undone; the cloud option can be cancelled any month.
  • A server is normally replaced after about five years.
  • Hosting contracts often require one to three months' notice to end.

Decision requested

Approval in principle of a budget of ฿170,000 for 15 months (expected about ฿125,000), with the server model to be confirmed from supplier quotes before purchase. Recommended only if the company wants to own the hardware; otherwise the cloud proposal is the lower-cost route for the same result.
