Proposal · ATC Fast-Time Simulation Tool

Running the simulation tool on a cloud server

A plan to host the tool on a rented server in Singapore for 15 months, so staff use it from a web browser with nothing to install.

From: BearCat AEL Co, engineering Date: 22 October 2026 Period: 15 months

What we propose

Today the tool runs as a program installed on each person's computer. We propose to also run it on a rented server (Railway, Singapore). Users open a web address, load a traffic file, and the server does the calculation. Nothing is installed on their computers and everyone always has the latest version. The same software already runs this way on a free test server; this proposal moves it to a paid server that is fast and reliable enough for real use.

Who would use it

  • Up to 10 staff in total; 2–4 on a typical day.
  • About 10 simulation runs per person per day, 1,000 flights each.
  • A 1,000-flight run takes about 50 seconds; 2,000 flights about 1.7 minutes.
  • If two people run at the same moment, each waits about twice as long. Sized for up to 10 people and 20 runs each.

Why this option

  • Nothing to install; works on any computer with a browser.
  • Everyone is on the latest version automatically.
  • Easy to demonstrate to people outside the office.
  • The installed desktop version stays available and costs nothing to run, including offline.

Before it goes live

About five working days of our own engineering time, in three weeks:

  • Set up the server in Singapore and measure a real run.
  • Tune the engine so it uses less memory when idle (this is what keeps the monthly cost near the minimum).
  • Add a password so only our staff can use it.
  • Register a web address.

Things to be aware of

  • Traffic files are processed on a server outside the office, in Singapore. Fine for simulation and demonstration data; to be reviewed before confidential data is used.
  • It needs an internet connection. The desktop version covers offline work.
  • The provider's prices may change; the bill will be checked monthly.
  • No formal uptime guarantee at this price level.

Decision requested

Approval of a budget of ฿35,000 for 15 months of cloud hosting (expected spend about ฿11,000), and about five days of engineering time to set it up.
